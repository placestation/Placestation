# mgn12-x-gantry

PlaceStation X-gantry toolhead mount redesigned for MGN12 linear rails.

## What changed

Stock LumenPnP uses different linear rail sizes across axes. PlaceStation standardises on **MGN12 rails throughout** the machine. This file contains the X-gantry toolhead mount modified to accept MGN12 rail carriages.

## Files

| File | Format | Description |
|------|--------|-------------|
| `Placestation_Toolhead.f3z` | Fusion 360 archive | Full parametric CAD source |
| `IMG_0494.HEIC` | Photo | Reference image of printed and assembled part |

## Notes

Adjacent mating parts may require minor adjustment depending on the specific MGN12 carriage you source. MGN12 is widely available from MISUMI, AliExpress, and Indian domestic suppliers.
