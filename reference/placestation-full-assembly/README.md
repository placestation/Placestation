# placestation-full-assembly

Full-machine Fusion 360 / STEP exports for reference.

## Files

| File | Format | Description |
|------|--------|-------------|
| `Placestation.step` | STEP | Full assembly export (open-format, works in FreeCAD, Fusion 360, SolidWorks, etc.) |

## Notes

These are **reference exports only** — not the authoritative source files for individual components. For editable source files of specific PlaceStation modifications, see the relevant folders under `hardware/`.
